# Benchmark data availability

This PR includes experiment reports, protocols and charts. Raw request payloads,
model responses, case datasets and intermediate analysis files remain in the
maintainer's local archive pending review for publication. References to those
files in reports describe that archive; they are not downloads from this checkout.

The benchmark scripts are included, but reproducing the reported analysis from
saved responses requires the corresponding archive. Running new experiments
also requires the model endpoint and dataset setup described in each protocol.
